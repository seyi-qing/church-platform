# API overview

Base path: `/api/v1`

- Auth: `/auth/register`, `/auth/login/json`, `/auth/refresh`, `/auth/me`
- Members: `/members/users`, `/members/profiles`, `/members/groups`, `/members/attendance`
- Media: `/media/items`, `/media/series`
- Events: `/events`, `/events/register`
- Livestream: `/livestream/sessions`, `/sessions/live`, `/{id}/start`, `/{id}/end`
- Giving: `/giving/intent`, `/giving/webhook`, `/giving/recurring/checkout`
- CMS: `/cms/pages`
- Care: `/care/requests`, `/care/workflow/board`
- Notifications: `/notifications/devices`, `/notifications/send`
- AI: `/ai/sermon-outline`, `/ai/prayer`, `/ai/summarize`, `/ai/chat`
- Analytics: `/analytics/overview`, `/analytics/giving-by-fund`

Interactive docs: `/docs` when the API is running.
